# Adding Custom Code

Add code to a new or existing stage. If your module needs additional dependencies, package them with [Add a Custom Environment](/curate-video/tutorials/pipeline-customization/add-cust-env).

## Before You Start

Before you add code, prepare your development environment:

* Read the [pipeline concepts and diagrams](/about/concepts/video).
* Set up a NeMo Curator development environment.
* Create a [custom environment](/curate-video/tutorials/pipeline-customization/add-cust-env) if your code needs additional packages or system dependencies.

---

## How to Add Custom Code

Define an importable class, then use it from a pipeline stage.

### Define New Functionality

1. Create a `custom_code` directory anywhere on your system to organize your custom pipeline code.
2. Create a new folder for your environment, for example: `new_stage/`.
3. Create a new file, for example `my_file.py`. This file must define a class (`MyClass`) made available for import.

   ```py
   # your code here
   ```

4. Import the class in your stage or pipeline code to use it.

   ```py
   from my_code.my_file import MyClass

   ...
   ```

5. Save the files.

### Use Your Code in a Pipeline

Create or edit a stage to use your code, then assemble a pipeline and run it in Python:

```py
from nemo_curator.pipeline import Pipeline
from nemo_curator.stages.base import ProcessingStage
from nemo_curator.tasks.video import VideoTask
from nemo_curator.stages.video.io.video_reader import VideoReader
from nemo_curator.stages.video.io.clip_writer import ClipWriterStage

from my_code.my_file import MyClass

class MyStage(ProcessingStage[VideoTask, VideoTask]):
    def process(self, task: VideoTask) -> VideoTask | list[VideoTask]:
        helper = MyClass()
        # use helper with task.data (Video/Clips)
        return task

pipeline = (
    Pipeline(name="my-pipeline")
    .add_stage(VideoReader(input_video_path="/path/to/videos", video_limit=10))
    .add_stage(MyStage())
    .add_stage(
        ClipWriterStage(
            output_path="/path/to/output",
            input_path="/path/to/videos",
            upload_clips=True,
            dry_run=False,
            generate_embeddings=False,
            generate_previews=False,
            generate_captions=False,
            embedding_algorithm="cosmos-embed1",
            caption_models=["qwen"],
            enhanced_caption_models=["qwen_lm"],
        )
    )
)

pipeline.run()
```

If your stage needs additional dependencies, add them to a custom image by following [Add a Custom Environment](/curate-video/tutorials/pipeline-customization/add-cust-env). Use the optional extras in `pyproject.toml` when they provide the packages you need.
