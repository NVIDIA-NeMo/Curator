# NeMo Curator Release Notes: 26.09 (Draft)

<Warning>
Draft for the planned 26.09 release. Confirm the final release tag before upgrading.
</Warning>

NeMo Curator 26.09 groups the latest data-ingestion, audio, pipeline, and semantic-deduplication updates. For upgrade actions, refer to the [26.09 migration checklist](/about/release-notes/26-09-migration). The [26.07 release notes](https://docs.nvidia.com/nemo/curator/v26.07/about/release-notes) remain available in the archived documentation version.

## What's New

- **Data ingestion and records:** Read and write Lance datasets and read WARC files from remote storage. Deduplication workflows add text normalization and ID/output controls, and Parquet writers preserve schemas.
- **Audio and evaluation:** Generic ASR supports `NeMoASRAdapter`, `QwenASRAdapter`, `QwenOmniASRAdapter`, and `FasterWhisperASR`. Transcript selection and normalization, sound-event inference and postprocessing, and the large language model (LLM) judge evaluation suite expand audio and evaluation coverage.
- **Pipeline contracts and scheduling:** Stages support multiple task types, infer fanout from `process` annotations, and can opt into per-node worker sizing. Ray Data adds scheduler diagnostics, and Ray Actor Pool adds configurable resource waits between stages. Refer to [Stage Worker Sizing](/reference/infra/stage-worker-sizing).
- **Semantic deduplication:** Pairwise processing uses bounded batches with a default `pairwise_batch_size` of `1024` and `float16` compute. KMeans can fit from a file-level sample before assigning the full Parquet input. Refer to [Semantic Deduplication](/curate-text/process-data/deduplication/semdedup) and validate output when changing precision.
- **Nemotron-Parse:** Examples use `InterleavedParquetWriterStage(path=...)`. Architecture-aware attention defaults improve in-process and Ray Serve inference on Ampere and Blackwell GPUs. The vLLM extra requires `quack-kernels>=0.4.1` for GB200 startup compatibility. Refer to [Nemotron-Parse PDF processing](/curate-text/load-data/nemotron-parse-pdf).
