# Get Started with Audio Curation

This guide helps you set up and get started with NeMo Curator's audio curation capabilities. Follow these steps to prepare your environment and run your first audio curation pipeline using the FLEURS dataset.

## Prerequisites

To use NeMo Curator's audio curation modules, ensure you meet the following requirements:

* Python 3.11, 3.12, or 3.13
  * packaging &gt;= 22.0
* uv (for package management and installation)
* **x86_64 Linux** (Ubuntu 22.04/20.04 recommended)
* NVIDIA GPU (recommended for ASR inference)
  * Volta™ or higher (compute capability 7.0+)
  * CUDA 12 (or above)
* Audio processing libraries (automatically installed with audio extras)
* An `ffmpeg` executable on `PATH` for stages that resample or convert audio

<Warning>
**Platform support:** Audio curation requires **x86_64 Linux**. The `audio_cpu` and `audio_cuda12` extras intentionally omit several dependencies on arm64/aarch64 (including NeMo ASR, diarization, and related tooling) because upstream packages do not ship aarch64 wheels. The arm64 NeMo Curator container therefore does not include the full audio stack. Use an amd64 host or container for ASR, diarization, and tagging workflows.
</Warning>

<Tip>
If you don't have `uv` installed, refer to the [Installation Guide](/get-started/installation) for setup instructions, or install it quickly with:

```bash
curl -LsSf https://astral.sh/uv/0.8.22/install.sh | sh
source $HOME/.local/bin/env
```

</Tip>

## Installation Options

You can install NeMo Curator with audio support in four ways:

<Tabs>
<Tab title="PyPI Installation">

The simplest way to install NeMo Curator with audio support:

```bash
echo "transformers==4.55.2" > override.txt
uv pip install "nemo-curator[audio_cuda12]" --override override.txt
```

<Note>
The audio extras include NeMo Toolkit with ASR models. Additional audio processing libraries (soundfile, editdistance) are installed automatically as NeMo Toolkit dependencies.
The extras do not install the `ffmpeg` command-line executable. For container and non-root installation options, refer to the [Installation Guide](/get-started/installation).
</Note>

</Tab>

<Tab title="Source Installation">

Install the latest version directly from GitHub:

```bash
git clone https://github.com/NVIDIA-NeMo/Curator.git
cd Curator
uv sync --extra audio_cuda12 --all-groups
source .venv/bin/activate
```

<Note>
Use `audio_cpu` for CPU-only audio processing, `audio_cuda12` for GPU acceleration, or `all` for all modalities.
</Note>

</Tab>

<Tab title="NeMo Curator Container">

NeMo Curator is available as a standalone container:

```bash
# Pull the container
docker pull nvcr.io/nvidia/nemo-curator:{{ container_version }}

# Run the container
docker run --gpus all -it --rm nvcr.io/nvidia/nemo-curator:{{ container_version }}
```

<Note>
For details on container environments and configurations, see [Container Environments](/reference/infra/container-environments).

</Note>

</Tab>
</Tabs>

## Run the Maintained FLEURS Pipeline

The repository maintains the executable tutorial in `tutorials/audio/fleurs/main.py` and its complete Hydra configuration in `tutorials/audio/fleurs/pipeline.yaml`. Run it from the repository root so the documentation and executable configuration stay synchronized:

If you installed the package from PyPI or are not already in a source checkout, clone the tutorial repository first:

```bash
git clone https://github.com/NVIDIA-NeMo/Curator.git
cd Curator
```

```bash
python tutorials/audio/fleurs/main.py \
  --config-path . \
  --config-name pipeline \
  raw_data_dir="${PWD}/example_audio/fleurs"
```

The maintained configuration downloads the Armenian (`hy_am`) development split, runs the matching FastConformer model, calculates `wer_pct` and duration, filters at `wer_pct <= 5.5`, and writes JSONL output. Its ASR configuration includes the required duration budget:

- `max_audio_sec_per_actor=240.0`
- `max_inference_duration_s=120.0`, which is no larger than the actor budget
- `local_bucketing=true`
- `stages.1.adapter_kwargs.use_cuda_graph_decoder=false` for broad hybrid-RNNT driver compatibility

An NVIDIA GPU is recommended, but not required. For CPU fallback, install the `audio_cpu` extra and override the ASR resource request:

```bash
python tutorials/audio/fleurs/main.py \
  --config-path . \
  --config-name pipeline \
  raw_data_dir="${PWD}/example_audio/fleurs-cpu" \
  stages.1.resources.gpus=0
```

Refer to the [Beginner Audio Processing Tutorial](/curate-audio/tutorials/beginner) for supported overrides and a walkthrough of the checked-in configuration.

## Expected Output

After running the pipeline, you'll have:

```text
example_audio/fleurs/
├── hy_am/                   # Downloaded Armenian data and source manifest
└── result/
    └── hy_am/               # Filtered JSONL output shards
```

Each output entry contains:

```json
{
    "audio_filepath": "/absolute/path/to/audio.wav",
    "text": "ground truth transcription",
    "pred_text": "asr model prediction",
    "wer_pct": 2.5,
    "duration": 4.2
}
```
