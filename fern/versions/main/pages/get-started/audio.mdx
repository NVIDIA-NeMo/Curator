# Quickstart for NeMo Curator Audio Curation

Use this quickstart to run NeMo Curator on a FLEURS audio dataset and inspect transcription-quality results. For complete setup details, refer to the [Installation Guide](/get-started/installation).

## Prerequisites

Prepare the following environment before running the audio pipeline:

- Python 3.11, 3.12, or 3.13 on x86_64 or aarch64 Linux. Ubuntu 20.04 or 22.04 is recommended.
- `packaging` 22.0 or later and Git.
- `uv` for package management.
- An `ffmpeg` executable on `PATH` for stages that resample or convert audio. The Python extras do not install it; audio workflows are easiest to reproduce in a [locally built container with FFmpeg](/reference/infra/container-environments#add-ffmpeg-for-audio-or-video). For Python package installs, refer to [FFmpeg installation options](/get-started/installation#install-ffmpeg-for-audio-and-video-source-installs).
- An NVIDIA Volta-class or newer GPU with compute capability 7.0 or later and CUDA 12 is recommended for ASR inference; the example also supports CPU execution.

<Warning>
On aarch64, `audio_cuda12` uses ONNX Runtime's CPU provider for workflows such as SIGMOS; it does not provide CUDA ONNX inference. NeMo ASR, Pyannote, WhisperX, TorchCodec, and NeMo text processing are included on both Linux architectures. Pynini has no ARM wheel: the Dockerfile and audio installer build its OpenFst prerequisites with `docker/common/install_openfst.sh`; run that script before a source installation of the audio extras on ARM. OpenAI Whisper, SpeechBrain, and Qwen ASR remain gated to x86-only. Check the individual dependency markers before selecting a workflow.
</Warning>

### Complete and Check an Existing Audio Environment

From a Curator source checkout, run the maintained audio dependency installer
inside the environment where Curator is already installed:

```bash
bash docker/common/install_audio.sh
bash docker/common/install_audio.sh --check
```

The installer prepares shared FFmpeg, installs the audio requirements declared
by this checkout, and selects a TorchCodec series and PyTorch wheel index matching
the installed Torch and CUDA build (or CPU build). It requires `uv` and does not reinstall Curator.
Python dependency repairs reuse FFmpeg when its audio capabilities already pass
`install_ffmpeg.sh --check-audio`; unrelated video capabilities are not required.
If audio capabilities are missing, the fallback installs the combined audio/video
FFmpeg build and requires root access.
It constrains installed Torch, TorchAudio, TorchVision, Numba, FSSpec, Transformers,
and Hugging Face Hub versions; NumPy must satisfy the installed Numba's bounds.
It retains Curator's existing uv override exceptions only when they match the
installed versions, including the Torch override required by WhisperX.
If those constraints conflict with the requested audio dependencies, installation
fails rather than replacing the inference stack. Such older-image conflicts need
separate validation; successful dependency resolution alone does not establish
compatibility.

`--check` never installs packages. It checks NeMo ASR, WhisperX, and WER stage imports,
verifies a NeMo text-normalization rewrite,
executes a small ONNX Runtime CPU model, and decodes generated FLAC and both
16-bit and float WAV files through TorchCodec and Pyannote. A Pyannote decoder
warning therefore cannot count as a successful check. Model downloads, GPU model
inference, and full benchmark correctness are not covered by these probes.

Benchmark environment setup discovers this installer automatically. Run only
one installer/setup process at a time in a shared environment.

## Quickstart Steps

Install Curator, run the maintained FLEURS pipeline, and inspect its output.

1. <a id="installation-options" />Install NeMo Curator. A locally built container is recommended for audio workflows so FFmpeg is available on every worker.

   <Tabs>
   <Tab title="Build an Image (Recommended)">

   Follow [Build an Image](/reference/infra/container-environments#build-an-image), then add FFmpeg using [Add FFmpeg for Audio or Video](/reference/infra/container-environments#add-ffmpeg-for-audio-or-video). This packages the audio system dependency in the image used by each worker.

   </Tab>
   <Tab title="Source Installation">

   The repository clone tracks development. For a released version, check out its published release tag before syncing.

   ```bash
   curl -LsSf https://astral.sh/uv/0.12.1/install.sh | sh
   source $HOME/.local/bin/env
   git clone https://github.com/NVIDIA-NeMo/Curator.git
   cd Curator
   uv sync --extra audio_cuda12 --all-groups
   source .venv/bin/activate
   ```

   Use `audio_cpu` for CPU-only processing. Replace `audio_cuda12` with `audio_cpu` in the `uv sync` command to use CPU-only processing.

   </Tab>
   <Tab title="PyPI Installation">

   For a specific release, verify that its package version is available on PyPI and matches the release notes.

   ```bash
   curl -LsSf https://astral.sh/uv/0.12.1/install.sh | sh
   source $HOME/.local/bin/env
   uv venv
   source .venv/bin/activate
   echo "transformers==4.55.2" > override.txt
   uv pip install "nemo-curator[audio_cuda12]" --override override.txt
   ```

   The audio extra installs NeMo Toolkit and its dependent audio-processing libraries. It does not install the `ffmpeg` executable.

   </Tab>
   </Tabs>

2. <a id="run-the-maintained-fleurs-pipeline" />Open a repository checkout. If you do not already have one, clone the source revision that matches your Curator installation.

   ```bash
   if [ ! -d .git ]; then
     git clone https://github.com/NVIDIA-NeMo/Curator.git
     cd Curator
   fi
   ```

3. Run the maintained FLEURS pipeline from the repository root.

   ```bash
   python tutorials/audio/fleurs/main.py \
     --config-path . \
     --config-name pipeline \
     raw_data_dir="${PWD}/example_audio/fleurs"
   ```

   The checked-in configuration downloads the Armenian (`hy_am`) development split, runs FastConformer ASR, calculates word error rate and duration, and filters at `wer_pct <= 5.5`.

   The configuration sets `max_audio_sec_per_actor=240.0`, `max_inference_duration_s=120.0`, `local_bucketing=true`, and `use_cuda_graph_decoder=false`. The 120-second inference limit is within the 240-second actor budget.

   For CPU execution, install the `audio_cpu` extra and set the GPU resource request to zero. Refer to the [Beginner Audio Processing Tutorial](/curate-audio/tutorials/beginner) for supported overrides and details about the checked-in configuration.

   ```bash
   python tutorials/audio/fleurs/main.py \
     --config-path . \
     --config-name pipeline \
     raw_data_dir="${PWD}/example_audio/fleurs-cpu" \
     stages.1.resources.gpus=0
   ```

4. <a id="expected-output" />Inspect the generated files and JSONL records. The output includes `audio_filepath`, `text`, `pred_text`, `wer_pct`, and `duration` fields.

   ```text
   example_audio/fleurs/
   ├── hy_am/                   # Downloaded Armenian data and source manifest
   └── result/
       └── hy_am/               # Filtered JSONL output shards
   ```

   ```json
   {
       "audio_filepath": "/absolute/path/to/audio.wav",
       "text": "ground truth transcription",
       "pred_text": "asr model prediction",
       "wer_pct": 2.5,
       "duration": 4.2
   }
   ```
