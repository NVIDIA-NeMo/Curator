# ASR Inference

Use `ASRStage` to transcribe audio with a supported model adapter.

## Choose an Adapter

The maintained tutorials show complete manifest-to-transcript pipelines for
these adapters:

| Adapter | Use When | Tutorial |
| --- | --- | --- |
| `NeMoASRAdapter` | You need an NVIDIA NeMo FastConformer checkpoint. | [NeMo FastConformer ASR tutorial](https://github.com/NVIDIA-NeMo/Curator/tree/main/tutorials/audio/nemo_fastconformer) |
| `QwenASRAdapter` | You need Qwen3-ASR transcription with language routing. | [Qwen3-ASR adapter tutorial](https://github.com/NVIDIA-NeMo/Curator/tree/main/tutorials/audio/qwen_asr) |
| `QwenOmniASRAdapter` | You need Qwen3-Omni in-process inference. | [Qwen3-Omni in-process ASR tutorial](https://github.com/NVIDIA-NeMo/Curator/tree/main/tutorials/audio/qwen_omni_inprocess) |
| `FasterWhisperASR` | You need Faster-Whisper Large-v3 transcription. | [Faster-Whisper adapter tutorial](https://github.com/NVIDIA-NeMo/Curator/tree/main/tutorials/audio/faster_whisper) |

Each tutorial includes its optional dependencies, executor settings, model
defaults, and a runnable command. The examples use GPU inference unless the
tutorial documents a CPU option.

Refer to [NeMo ASR models](/curate-audio/process-data/asr-inference/nemo-models)
for the NeMo model catalog and model-specific guidance.

## Configure the Stage

Set `adapter_target` to the adapter import path and `model_id` to the model
checkpoint. The following example shows the shared stage interface:

```python
from nemo_curator.stages.audio.inference.asr.stage import ASRStage
from nemo_curator.stages.resources import Resources

asr = ASRStage(
    adapter_target="nemo_curator.models.asr.nemo_asr.NeMoASRAdapter",
    model_id="nvidia/stt_en_fastconformer_ctc_large",
    audio_filepath_key="audio_filepath",
    pred_text_key="pred_text",
    batch_size=16,
    resources=Resources(gpus=1.0),
)
```

Use the adapter-specific tutorial when you need `adapter_kwargs`. Those
settings stay with the adapter that implements them. Set `resources.gpus` to
the number of GPUs each worker receives.

## Provide Input Audio

Each `AudioTask` must provide an audio path under the key configured by
`audio_filepath_key`. The default key is `resampled_audio_filepath`, so place a
`ResampleAudioStage` before `ASRStage`, or point the stage at an existing audio
path. The stage loads audio for the current batch and normalizes it to mono at
`target_sample_rate` (16 kHz by default) before inference.

For manifest pipelines, each JSONL row can contain an audio path and optional
language metadata:

```json
{"audio_filepath": "/data/sample.wav", "source_lang": "en"}
```

Set `source_lang_key` to use another language field. Set `default_language`
when rows do not contain language metadata. If you set
`supported_language_codes`, rows outside that list remain in the output with a
language skip reason instead of being sent to the adapter.

## Read Output

The stage preserves input fields and writes the transcript to `pred_text_key`,
which defaults to `pred_text`. Set `extras_key` to store adapter-specific
serializable metadata in one nested field. The stage can also write these
control fields:

| Field | Meaning |
| --- | --- |
| `pred_text` | Transcript text; skipped results can contain an empty string. |
| `_skipme` | Machine-readable reason for a skipped row. |
| `additional_notes` | Additional stage or adapter diagnostics. |
| Configured `extras_key` | Adapter-specific metadata when the adapter returns it. |

Skipped results remain in the output with `_skipme`. By default, an unreadable
audio file receives an `audio_load_error` skip reason; set
`fail_on_audio_error` to `True` when that audio error must fail the pipeline.
Model loading and adapter inference errors propagate to the pipeline. Inspect
`_skipme` and `additional_notes` before consuming the output manifest.

## Tune Batching and Resources

Set `batch_size` to control how many tasks the executor sends to one adapter
call. Start with the tutorial value, then reduce it when the model exceeds GPU
memory. Use the tutorial's documented CPU configuration when the selected
adapter supports CPU inference.
