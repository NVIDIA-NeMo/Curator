# GranaryHiFi: Annotated Manifests from Granary

Turn Granary ASR manifests (one JSONL row per recording with tar-member audio segments) into annotated JSONL
manifests: speaker, quality and sound-event annotations, a same-speaker context clip, IPA, end-of-word verdicts and
training flags, with the segments that fail any gate dropped. Source: `tutorials/audio/granary_hifi/`.

## Install

```bash
uv sync --extra audio_tts
uv pip install git+https://github.com/sarulab-speech/UTMOSv2.git
```

Also needed: `espeak-ng` (1.51 or 1.52) and Montreal Forced Aligner 3.4.1 on `PATH`. Every model downloads on first
use. ReUse enhancement runs `resemble-enhance` in a separate Python environment.

## Run

```bash
python tutorials/audio/granary_hifi/run.py annotate --preset ytc \
  --input_manifest in.jsonl --output_manifest annotated/ --tar_root /data/audio --mfa_root_dir /opt/mfa
```

`annotate` runs diarization, speaker clustering, sound-event detection, UTMOSv2, bandwidth, the segment filter,
context selection, IPA, the early cut-off check, training flags and the training filter on the original audio, then
optionally enhances the kept segments and their context clips (`--enhancement studio_voice|reuse`). See
`run.py annotate --help` for all flags.

Packing the result into Lhotse SHAR shards and extracting neural codec codes are available as Curator stages
(`LhotseSharBuildStage`, `CodecCodesStage`, `SharValidationStage`) but are not part of this pipeline.
