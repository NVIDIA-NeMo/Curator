# GranaryHiFi: TTS Training Shards from Granary

Turn Granary ASR manifests (one JSONL row per recording with tar-member audio segments) into Lhotse SHAR shards with
target/context audio, IPA, neural codec codes and training flags. Source: `tutorials/audio/granary_hifi/`.

## Install

```bash
uv sync --extra audio_tts
uv pip install git+https://github.com/sarulab-speech/UTMOSv2.git
```

Also needed: `espeak-ng` (1.51 or 1.52) and Montreal Forced Aligner 3.4.1 on `PATH`, the early cut-off endpoint
bundle, and the model files listed in the tutorial README. ReUse enhancement runs `resemble-enhance` in a separate
Python environment.

## Run

```bash
python tutorials/audio/granary_hifi/run.py annotate --preset ytc \
  --input_manifest in.jsonl --output_manifest annotated/ --tar_root /data/audio \
  --sed_classifier gbt_multiclass_model.joblib \
  --early_cut_off_bundle_dir endpoint_bundle/ --mfa_root_dir /opt/mfa

python tutorials/audio/granary_hifi/run.py build_shar --preset ytc --language it \
  --input_manifest 'annotated/*.jsonl' --tar_root /data/audio --shar_dir shar/ \
  --codec_model nvidia/nemo-nano-codec-22khz-1.89kbps-21.5fps --publish_root published/
```

`annotate` runs optional enhancement (`--enhancement studio_voice|reuse`), diarization, speaker clustering, sound-event
detection, UTMOSv2, bandwidth, the segment filter, context selection, IPA, the early cut-off check and training flags.
`build_shar` writes speaker-grouped shards, codec codes, validates and publishes them. With enhancement on, every later
step and the shards use the enhanced audio. `--codec_model` also accepts a local `.nemo` codec. See
`run.py annotate --help` and `run.py build_shar --help` for all flags.
