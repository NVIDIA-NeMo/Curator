## More Tutorials in the Repository

These tutorials live in [`tutorials/audio`](https://github.com/NVIDIA-NeMo/Curator/tree/main/tutorials/audio). Each README lists its environment, sample data, and commands.

| Tutorial | What it shows |
|---|---|
| [MFA forced alignment](https://github.com/NVIDIA-NeMo/Curator/tree/main/tutorials/audio/alignment) | Align audio with transcripts using `MFAAlignmentStage` |
| [Audio tagging](https://github.com/NVIDIA-NeMo/Curator/tree/main/tutorials/audio/tagging) | Turn raw audio into labeled TTS or ASR data with diarization, ASR alignment, and segment preparation |
| [Chatterbox TTS synthesis](https://github.com/NVIDIA-NeMo/Curator/tree/main/tutorials/audio/tts) | Synthesize multi-speaker conversations with `ChatterboxTTSStage` and `MergeConversationSDPStage` |
| [Whole-recording Sortformer diarization](https://github.com/NVIDIA-NeMo/Curator/tree/main/tutorials/audio/sortformer) | Run Streaming Sortformer v2.1 over a JSONL manifest |
| [CallHome speaker diarization](https://github.com/NVIDIA-NeMo/Curator/tree/main/tutorials/audio/callhome_diar) | Diarize CallHome English with Sortformer and compute DER |
| [Single-speaker filtering](https://github.com/NVIDIA-NeMo/Curator/tree/main/tutorials/audio/single_speaker_filter) | Keep only files with exactly one speaker |
| [Long-form audio cutting](https://github.com/NVIDIA-NeMo/Curator/tree/main/tutorials/audio/audio_pretrain) | Source for the [Long-Form Audio Cutting](/curate-audio/tutorials/audio-pretrain) tutorial |

For per-stage details, refer to the [Audio Stage Reference](/curate-audio/process-data/stage-reference).
